=== Vulnerability Analysis ===

Root Cause: sprintf() formats user-controlled newid (v7) into a shell command
string without any shell metacharacter escaping, then passes to system().

Filter Bypass: check_id_char() only rejects characters < 33, ':' (58), and DEL (127).
This allows ';' (59) to pass through, which shell interprets as a command separator.

Payload: newid = "a;pwd>/tmp/q"
  → sprintf produces: "chpasswd.sh a;pwd>/tmp/q x"
  → shell executes:   chpasswd.sh a  |  pwd>/tmp/q  |  x
  → second command (pwd>/tmp/q) runs as root

Auth Bypass: landap_authentication() passes when sys_password is empty (factory default).
  Code: if (!v8 || !memcmp(v5, &sys_password, v7)) return 0;
  When sys_password empty, v7 = strlen(sys_password) = 0,
  memcmp(anything, anything, 0) always returns 0 → auth passes.
